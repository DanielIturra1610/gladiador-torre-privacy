# Gladiador Torre — Privacy Policy

Public privacy policy for **Gladiador Torre**, a mobile match-3 roguelite for Android (Google Play).

- Live page: https://danieliturra1610.github.io/gladiador-torre-privacy/
- Languages: Spanish and English (same page).
- Summary: the game does not collect, store or share personal data; it has no ads and no in-app purchases.

This repository only hosts the policy page via GitHub Pages. To update it, edit `index.html` and push to `main`.
